# @mentions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Typing `@` in a comment or task description inserts a workspace member as a chip, stored as `[@Name](mention:<userId>)` in the Markdown, and the mentioned member gets a bell item + toast.

**Architecture:** A shared pure module (`src/lib/mentions.ts`) owns the link format: the regex, id extraction, plain-text conversion and member filtering. The server diffs mention ids on every comment/description write and upserts a new `mention` notification kind in the same transaction, coalesced per (recipient, task, actor) while unread. The editor uses `@tiptap/extension-mention` with its three Markdown hooks replaced; `Markdown.tsx` renders `mention:` links as chips.

**Tech Stack:** Next.js 16, Drizzle + Postgres (`drizzle-kit push`), Tiptap 3.31.3 (`@tiptap/markdown`, `@tiptap/suggestion`), cmdk + tippy.js, react-markdown 10, Vitest 4 (node + jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-08-mentions-design.md`

## Review Focus

1. **Assignee/creator who is also mentioned in a comment** — expects one bell item (the mention), not a mention plus "commented". Pinned in Task 4 (`no second item for the creator who is mentioned`).
2. **Description edit that also changes status** — the mentioned creator should still hear "moved to Done"; only the `description` part is covered by the mention. Pinned in Task 4 (`keeps other changes for a mentioned recipient`).
3. **Editing a comment without touching its mentions** (typo fix) — no new notification. Pinned in Task 4 (`re-saving with the same mention notifies nobody`).
4. **Mention-shaped text inside code** (`` `[@Ana](mention:x)` `` in a code span or fence) — plain text, no notification. Pinned in Task 1 and Task 5.
5. **Escape while the @ menu is open inside the task dialog** — closes the menu only, not the dialog or the description editor. Pinned in Task 5 (`handleEditorEscape` covers the mention plugin) and Task 7 e2e.

```ts
// src/lib/mentions.ts
/**
 * @mentions live in Markdown as `[@Display Name](mention:<userId>)`. The display name is the
 * member's name when mentioned: readers without the member list (REST API, ex-members) see it.
 * Shared by the editor (src/components/kibo-ui/editor/mention.tsx), the renderer
 * (src/components/task/Markdown.tsx) and the server (src/server/notifications/changes.ts).
 */

export const MENTION_SCHEME = 'mention:';

/** Two groups: the escaped label and the id. No anchors and no flags, so callers add their own. */
export const MENTION_LINK_SOURCE = String.raw`\[@((?:\\.|[^\]\\])*)\]\(mention:([A-Za-z0-9_-]+)\)`;

export function escapeMentionLabel(label: string): string {
  return label.replace(/([\\[\]])/g, '\\$1');
}

export function unescapeMentionLabel(raw: string): string {
  return raw.replace(/\\(.)/g, '$1');
}

export function mentionMarkdown(id: string, label: string): string {
  return `[@${escapeMentionLabel(label)}](${MENTION_SCHEME}${id})`;
}

/** Code is not prose: a mention-shaped string inside it is text, not a mention. */
function withoutCode(markdown: string): string {
  return markdown.replace(/```[\s\S]*?(```|$)/g, ' ').replace(/`[^`\n]*`/g, ' ');
}

export function extractMentionIds(markdown: string): string[] {
  const ids = new Set<string>();
  for (const match of withoutCode(markdown).matchAll(new RegExp(MENTION_LINK_SOURCE, 'g'))) ids.add(match[2]);
  return [...ids];
}

export function mentionsToText(markdown: string): string {
  return markdown.replace(new RegExp(MENTION_LINK_SOURCE, 'g'), (_, label: string) => `@${unescapeMentionLabel(label)}`);
}

export function filterMembers<T extends { name: string; email: string }>(members: T[], query: string, limit = 8): T[] {
  const q = query.trim().toLowerCase();
  return members
    .filter((m) => !q || m.name.toLowerCase().includes(q) || m.email.toLowerCase().includes(q))
    .slice(0, limit);
}
```

```ts
export async function notifyMentions(
  ctx: WorkspaceContext,
  tx: Executor,
  input: { taskId: string; userIds: string[]; where: MentionWhere; comment?: string },
): Promise<string[]> {
  if (input.userIds.length === 0) return [];

  const [row] = await tx
    .select({ title: task.title, projectName: project.name })
    .from(task)
    .innerJoin(project, eq(project.id, task.projectId))
    .where(and(eq(task.id, input.taskId), eq(task.workspaceId, ctx.workspaceId)))
    .limit(1);
  if (!row) return [];

  // A mention is addressed to someone: the change-notification toggle does not mute it.
  const ids = await recipients(ctx, tx, [...new Set(input.userIds)], { respectToggle: false });
  if (ids.length === 0) return [];

  const data: MentionData = {
    title: row.title,
    projectName: row.projectName,
    actorName: await actorName(ctx, tx),
    where: [input.where],
    ...(input.comment ? { comment: input.comment } : {}),
  };
  const json = JSON.stringify(data);

  await tx.execute(sql`
    INSERT INTO notification AS n (id, user_id, workspace_id, kind, task_id, actor_id, dedupe_key, data, created_at)
    VALUES ${values(ids.map((userId) => sql`(
      ${newId()}, ${userId}, ${ctx.workspaceId}, 'mention', ${input.taskId}, ${ctx.userId},
      ${`mtn:${newId()}`}, ${json}::jsonb, clock_timestamp()
    )`))}
    ON CONFLICT (user_id, task_id, actor_id) WHERE kind = 'mention' AND read_at IS NULL
    DO UPDATE SET
      data = EXCLUDED.data
        || jsonb_build_object('where', ${mergedChanges([], 'where')})
        || ${keepStored('comment')},
      created_at = clock_timestamp()
  `);
  return ids;
}
```

```tsx
'use client';

/**
 * @mentions — @tiptap/extension-mention with its Markdown hooks replaced: it writes a shortcode
 * (`[@ id="…" label="…"]`) out of the box; ours is a link, `[@Name](mention:<id>)`
 * (src/lib/mentions.ts), which reads as "@Name" anywhere the editor is absent. The popup copies
 * the slash menu (slash.tsx): cmdk with the editor keeping focus, keys forwarded, mounted inside
 * the surrounding dialog.
 */

import type { AnyExtension } from '@tiptap/core';
import Mention from '@tiptap/extension-mention';
import { PluginKey } from '@tiptap/pm/state';
import { ReactRenderer } from '@tiptap/react';
import { Command } from 'cmdk';
import tippy, { type Instance as TippyInstance } from 'tippy.js';
import { UserAvatar } from '@/components/auth/user/user-avatar';
import { filterMembers, MENTION_LINK_SOURCE, mentionMarkdown, unescapeMentionLabel } from '@/lib/mentions';

export type MentionMember = { userId: string; name: string; email: string; image: string | null };

type MenuProps = { items: MentionMember[]; command: (attrs: { id: string; label: string }) => void };

function MentionMenu({ items, command }: MenuProps) {
  return (
    <Command
      // Remount on a new item set: cmdk would otherwise keep a highlight on a filtered-out value.
      key={items.map((m) => m.userId).join('|')}
      id="mention-menu"
      label="Mention someone"
      shouldFilter={false}
      onKeyDown={(event) => event.stopPropagation()}
      className="w-64 overflow-hidden rounded-2xl bg-bg-white-0 p-1.5 shadow-regular-md ring-1 ring-inset ring-stroke-soft-200"
    >
      <Command.List>
        {items.map((m) => (
          <Command.Item
            key={m.userId}
            value={m.userId}
            onSelect={() => command({ id: m.userId, label: m.name })}
            className="flex cursor-pointer items-center gap-2 rounded-lg px-2 py-1.5 data-[selected=true]:bg-bg-weak-50"
          >
            <UserAvatar user={{ name: m.name, image: m.image }} aria-hidden="true" className="size-6 text-[0.625rem]" />
            <span className="flex min-w-0 flex-col">
              <span className="truncate text-label-sm text-text-strong-950">{m.name}</span>
              <span className="truncate text-paragraph-xs text-text-sub-600">{m.email}</span>
            </span>
          </Command.Item>
        ))}
      </Command.List>
    </Command>
  );
}

function forwardToMenu(event: KeyboardEvent) {
  if (!['ArrowUp', 'ArrowDown', 'Enter'].includes(event.key)) return false;
  const menu = document.querySelector('#mention-menu');
  if (!menu) return false;
  event.preventDefault();
  menu.dispatchEvent(new KeyboardEvent('keydown', { key: event.key, cancelable: true, bubbles: true }));
  return true;
}

export const mentionPluginKey = new PluginKey('mention');

const LINK_AT_START = new RegExp(`^${MENTION_LINK_SOURCE}`);
const LINK_ANYWHERE = new RegExp(MENTION_LINK_SOURCE);

/** `getMembers` is read on every keystroke, so a changed member list needs no editor rebuild. */
export function createMentionExtension(getMembers: () => MentionMember[]): AnyExtension {
  return Mention.extend({
    markdownTokenizer: {
      name: 'mention',
      level: 'inline',
      start: (src: string) => src.search(LINK_ANYWHERE),
      tokenize(src: string) {
        const match = src.match(LINK_AT_START);
        if (!match) return undefined;
        return { type: 'mention', raw: match[0], attributes: { label: unescapeMentionLabel(match[1]), id: match[2] } };
      },
    },
    parseMarkdown: (token, helpers) => helpers.createNode('mention', token.attributes),
    renderMarkdown: (node) => mentionMarkdown(String(node.attrs?.id ?? ''), String(node.attrs?.label ?? '')),
  }).configure({
    HTMLAttributes: { class: 'mention' },
    renderText: ({ node }) => `@${node.attrs.label}`,
    renderHTML: ({ options, node }) => ['span', options.HTMLAttributes, `@${node.attrs.label}`],
    suggestion: {
      char: '@',
      pluginKey: mentionPluginKey,
      items: ({ query }) => filterMembers(getMembers(), query),
      render: () => {
        let component: ReactRenderer<unknown, MenuProps> | undefined;
        let popup: TippyInstance | undefined;
        let hasItems = false;
        return {
          onStart: (props) => {
            hasItems = props.items.length > 0;
            component = new ReactRenderer(MentionMenu, { props, editor: props.editor });
            popup = tippy(document.body, {
              getReferenceClientRect: () => props.clientRect?.() ?? new DOMRect(),
              appendTo: () => props.editor.view.dom.closest('[role="dialog"]') ?? document.body,
              content: component.element,
              showOnCreate: hasItems,
              interactive: true,
              trigger: 'manual',
              placement: 'bottom-start',
            });
          },
          onUpdate: (props) => {
            hasItems = props.items.length > 0;
            component?.updateProps(props);
            popup?.setProps({ getReferenceClientRect: () => props.clientRect?.() ?? new DOMRect() });
            if (hasItems) popup?.show();
            else popup?.hide();
          },
          onKeyDown: ({ event }) => {
            if (event.key === 'Escape') {
              popup?.hide();
              return true;
            }
            return hasItems && forwardToMenu(event);
          },
          onExit: () => {
            popup?.destroy();
            component?.destroy();
          },
        };
      },
    },
  });
}
```

```tsx
import ReactMarkdown, { defaultUrlTransform, type Components } from 'react-markdown';
import type { MentionMember } from '@/components/kibo-ui/editor/mention';
import { MENTION_SCHEME } from '@/lib/mentions';
```

```tsx
/** react-markdown empties unknown schemes; mention: is ours and never becomes an href. */
const urlTransform = (url: string) => (url.startsWith(MENTION_SCHEME) ? url : defaultUrlTransform(url));

function buildComponents(members?: MentionMember[], currentUserId?: string): Components {
  return {
    // react-markdown's URL transform has already emptied unsafe hrefs
    // (javascript:, data:, …) by the time this runs.
    a: ({ href, children }) => {
      if (href?.startsWith(MENTION_SCHEME)) {
        const id = href.slice(MENTION_SCHEME.length);
        const name = members?.find((m) => m.userId === id)?.name;
        return (
          <span className="mention" {...(id === currentUserId ? { 'data-self': '' } : {})}>
            {name ? `@${name}` : children}
          </span>
        );
      }
      return (
        <a href={href} target="_blank" rel="noopener noreferrer">
          {children}
        </a>
      );
    },
    // A remote image would load in every viewer's browser, telling its host who read the
    // task and when. The editor cannot make images, so show them as links.
    img: ({ src, alt }) => {
      const href = typeof src === 'string' ? src : undefined;
      return (
        <a href={href} target="_blank" rel="noopener noreferrer">
          {alt || href}
        </a>
      );
    },
  };
}

export function Markdown({
  children, className, members, currentUserId,
}: { children: string; className?: string; members?: MentionMember[]; currentUserId?: string }) {
  return (
    <div className={cn('md-content', className)}>
      <ReactMarkdown
        remarkPlugins={[remarkGfm, remarkBreaks, remarkHtmlAsText]}
        components={buildComponents(members, currentUserId)}
        urlTransform={urlTransform}
      >
        {children}
      </ReactMarkdown>
    </div>
  );
}
```

`mention.tsx` is `'use client'` but only its type is imported here (`import type`), so `Markdown` stays usable from server components.
